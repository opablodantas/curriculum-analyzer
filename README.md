
# Currículo Analytics (nome provisório)

## 📌 Visão Geral

O **Currículo Analytics** nasceu da observação de um problema recorrente em lojas de varejo: a dificuldade do setor de RH em selecionar candidatos de forma rápida e eficaz para preencher vagas disponíveis.
Este projeto propõe uma **aplicação web interativa** que auxilie o time de RH na **triagem de currículos**, oferecendo **análises automáticas** e sugestões baseadas na compatibilidade dos candidatos com a vaga informada.

---

## 🎯 Objetivo

Ajudar o setor de Recursos Humanos a:

* Agilizar o processo de triagem de candidatos.
* Obter uma análise comparativa clara entre diferentes currículos.
* Tomar decisões com base em dados e insights fornecidos por inteligência artificial.

---

## 🧩 Como Funciona

1. **Cadastro da vaga**:
   O gestor preenche as informações detalhadas sobre a vaga desejada (habilidades, experiência, requisitos, etc.).

2. **Envio de currículos**:
   O RH faz o upload de currículos de até **3 candidatos** (número ajustável futuramente).

3. **Análise automatizada**:
   A aplicação processa as informações e:

   * Avalia cada candidato com base na vaga cadastrada.
   * Gera uma **pontuação de compatibilidade** individual.
   * Apresenta uma **análise comparativa** entre os candidatos.
   * Sugere uma **conclusão baseada nos dados** obtidos.

4. **Decisão final**:
   Com base nas informações fornecidas, o RH poderá tomar uma decisão mais embasada e eficiente.

## 🛠️ Tecnologias Utilizadas

* **Python**
  Linguagem base do projeto, escolhida por seu vasto ecossistema para manipulação de dados, integração com IA e construção de aplicações.

* **Streamlit / Streamlit Cloud**
  Framework para desenvolvimento rápido de aplicações web interativas com Python.

* **LLM (modelo de linguagem a ser definido)**
  Para realizar a análise semântica dos currículos e das descrições das vagas.

* **Phidata**
  Biblioteca para criação de agentes de IA personalizados que auxiliarão na análise e comparação de candidatos.

* **Groq**
  Plataforma de hospedagem de modelos de linguagem em nuvem com alto desempenho.
